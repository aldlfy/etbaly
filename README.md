## 🌟 نظرة عامة (Overview)

تم تصميم **ExamForge (اطبعلي)** خصيصاً لتلبية احتياجات المعلمين والمدرسين في الوطن العربي والعراق لصياغة وتنسيق أوراق امتحانات رسمية مطابقة للمواصفات الوزارية القياسية بنقرة زر واحدة. يعمل التطبيق كـ **Single Page Application (SPA)** بالكامل على متصفح العميل دون الحاجة لخادم تخزين للامتحانات، حيث يتم حفظ كافة البيانات محلياً على جهاز المعلم لضمان الخصوصية والسرعة الفائقة والعمل بدون إنترنت (Offline-First).

## 🚀 المميزات الرئيسية (Core Features)

### 1. ترويسة وزارية قياسية وشبكة تصحيح رسمية
* ترويسة وزارية ثلاثية الأعمدة (الجمهورية، الوزارة، المديرية، المدرسة، المادة، الصف، الدور، العام الدراسي).
* دعم كامل لشعار المدرسة مع إمكانية رفعه وتغيير موضعه (يمين، وسط، يسار) وحفظه محلياً كـ Blobs في IndexedDB.
* شبكة توزيع الدرجات الوزارية الرسمية (Grading Grid) المعتمدة في لجان الفحص والتدقيق.

### 2. محرر رياضي وعلمي مانع لتداخل الاتجاهات (Anti-Bidi Corruption Engine)
* محرر غني مبني على **Tiptap** مدمج مع **KaTeX** و **mhchem**.
* عزل ذكي للمعادلات والصيغ الإنجليزية داخل النصوص العربية باستخدام `<bdi dir="ltr">` و `<span dir="ltr">` لمنع انقلاب الأقواس وتداخل النصوص المختلطة.
* لوحة رموز بصرية سريعة لإدراج الكسور، الجذور، التكاملات، المصفوفات، المتجهات، التفاعلات الكيميائية، والأسس.
* بنك نماذج علمية متقدمة يحتوي على 30 مسألة نموذجية في الرياضيات والفيزياء والكيمياء.

### 3. منشئ الأسئلة المتعدد الأنماط (Question Builder Studio)
يدعم 7 أنواع مختلفة من الأسئلة الامتحانية:
1. **أسئلة المقال والشرح (Essay)**.
2. **الأسئلة المتفرعة (Multi-part)** بفروع مرقمة أبجدياً `(أ، ب، ج)` مع درجات مستقلة لكل فرع.
3. **الاختيار من متعدد (MCQ)** بتنسيق أفقي، عمودي، أو شبكي (Grid) مع خيارات رياضية.
4. **صح أو خطأ (True/False)** مع تصحيح الخطأ وتوزيع الدرجات.
5. **املأ الفراغات (Fill in the blanks)**.
6. **المطابقة والتوصيل (Matching Pairs)** بين عمودين.
7. **المسائل الحسابية مع مساحات إجابة مخصصة (Calculation)** تشمل أسطر منقطة، أسطر مصمتة، أو شبكة مربعات هندسية.
* إحصاء فوري لمجموع درجات الورقة وتنبيه في حال عدم تطابق الدرجات مع الدرجة الكلية المستهدفة.

### 4. محرك التقسيم والتنسيق الطباعي (Pagination Engine & A4 Print)
* محاكاة دقيقة 100% لما يخرج على طابعة A4 أو A3.
* تقسيم ديناميكي لصفحات الاختبار بدون كسر الأسئلة في المنتصف (Smart Avoid Break).
* ترويسة مصغرة (Mini-Header) تظهر تلقائياً على الصفحات التالية.
* تحكم في الهوامش (ضيقة، قياسية، عريضة)، والخطوط العربية (Cairo, Amiri, Tajawal, Noto Naskh)، والأرقام (مشرقية ١٢٣ أو مغربية 123).
* خيار تقسيم الصفحة إلى عمودين مع فاصل وسطي وخوارزمية "Fit to 1/2 Pages" لضغط الأسئلة توفيراً للورق.

### 5. بنك الأسئلة، النماذج المسبقة، وإدارة الاختبارات (Local Storage & Bank)
* تخزين سحابي محلي فائق السرعة عبر **IndexedDB (Dexie.js)**.
* حفظ تلقائي ذكي بعد التعديل (Debounced Autosave).
* تصدير واستيراد الاختبارات بصيغة JSON لمشاركتها مع الزملاء.
* بنك أسئلة محلي مصنف حسب المادة، الصف، والنوع.
* مكتبة نماذج وزارية جاهزة (فيزياء رابع علمي، رياضيات سادس علمي، كيمياء ثالث متوسط) للتحميل بنقرة واحدة.

### 6. نماذج متعددة (أ / ب) وسلالم تصحيح وأوراق تظليل (Variants & Bubble Sheets)
* توليد تلقائي للنموذج (أ) والنموذج (ب) مع خلط الأسئلة وخيارات الاختيار من متعدد لمنع الغش.
* توليد **سلم التصحيح الوزاري المعتمد (Answer Key Sheet)** المتضمن خطوات الحل والدرجات.
* توليد **ورقة التظليل الضوئي (Bubble Sheet)** للاختبارات المؤتمتة مع باركود تعريفي.

### 7. نظام الحسابات ورموز التفعيل (Supabase Auth & Subscriptions)
* إدارة المستخدمين عبر Supabase Auth.
* نظام تفعيل مسبق الدفع بواسطة رموز التفعيل بصيغة `XXXX-XXXX-XXXX`.
* دالات قاعدة بيانات آمنة `SECURITY DEFINER` تتحقق من تشفير SHA-256 للرمز دون كشف الأسرار للمتصفح.
* لوحة تحكم المشرف (Admin Dashboard) لتوليد حزم الرموز الجديدة، إبطال الرموز، وتصديرها بصيغة CSV.

### 8. المساعد الذكي لإعداد الأسئلة (AI Assistant Proxy Worker)
* Cloudflare Worker آمن وسريع يربط بين واجهة المستخدم و Gemini AI.
* التحقق من اشتراك المستخدم وصلاحيته (Entitlement Check) قبل إرسال الطلب.
* محرك ذكي داخلي (Curriculum Fallback Engine) لتوليد الأسئلة أوفلاين في حال انقطاع الاتصال.

## 🛠️ البنية التقنية (Architecture & Tech Stack)

| المكون | التقنية المستخدمة | الغرض |
| :--- | :--- | :--- |
| **Frontend Core** | React 18, TypeScript (Strict), Vite | واجهة مستخدم سريعة وخفيفة ومنيعة للأخطاء |
| **Styling** | Tailwind CSS (Logical RTL), Vanilla CSS | تصميم راقٍ وسلس يدعم الوضع الليلي والنهاري واتجاه RTL |
| **Offline Storage** | Dexie.js (IndexedDB) | تخزين الاختبارات، المسائل، وبنك الأسئلة محلياً |
| **Math & Science** | KaTeX, mhchem | تصيير الرموز والمعادلات الرياضية والكيميائية |
| **Typography** | Cairo, Amiri, Tajawal, Noto Naskh | خطوط عربية مدمجة تدعم الطباعة عالية الدقة |
| **Testing** | Vitest, Happy-DOM | 11 ملف اختبار بأكثر من 44 اختبار وحدة شامل |
| **Backend / Auth** | Supabase (PostgreSQL + RLS + RPC) | إدارة الحسابات، التحقق من رموز التفعيل بصلاحيات آمنة |
| **AI Gateway** | Cloudflare Workers (TypeScript) | وسيط آمن لحماية مفاتيح API وتوليد الأسئلة |

## 💻 التشغيل المحلي والتطوير (Local Setup)

### المتطلبات الأساسية
- Node.js (الإصدار 18 أو 20 أو أحدث).
- npm أو pnpm أو yarn.

### الخطوات:
```bash
# 1. استنساخ المستودع
git clone https://github.com/aldlf/examforge.git
cd examforge

# 2. تثبيت الحزم البرمجية
npm install

# 3. إعداد متغيرات البيئة (اختياري، مدمج افتراضياً مع Supabase)
cp .env.example .env

# 4. تشغيل خادم التطوير المحلي
npm run dev
```

افتح المتصفح على العنوان `http://localhost:3000`.

### فحص الكود والاختبارات:
```bash
# تشغيل جميع اختبارات الوحدة (Vitest)
npm run test

# فحص المعايير والتنسيق (ESLint مع صفر تحذيرات)
npm run lint

# فحص الأنواع الصارمة في TypeScript
npx tsc --noEmit

# بناء النسخة الإنتاجية للطباعة والنشر
npm run build
```

## 🌐 النشر على GitHub Pages (Deployment)

تم تهيئة المشروع بالفعل للنشر الآلي على GitHub Pages عبر GitHub Actions:
1. عند دفع التغييرات (Push) إلى فرع `main`، يعمل سير العمل `.github/workflows/deploy.yml`.
2. يتم تشغيل الاختبارات وفحص الكود وبناء الحزم المصغرة في مجلد `dist`.
3. يتولى الإجراء رفع ونشر الموقع مباشرة مع دعم ملف `404.html` لتوجيه مسارات الـ SPA بدقة.

للنشر اليدوي أو عبر مستودعك الخاص:
- اضبط في إعدادات المستودع (Settings -> Pages) المصدر ليكون **GitHub Actions**.

## 🗄️ إعداد قاعدة بيانات Supabase (Database Setup)

توجد ملفات الهجرة (Migrations) داخل المجلد `supabase/migrations/`:
1. `20261019_initial_schema.sql`: جداول `user_profiles`, `subscriptions`, `activation_codes`, `code_redemptions`.
2. `20261019_rls_policies.sql`: سياسات أمان مستوى الصف (RLS).
3. `20261019_rpc_functions.sql`: دوال `redeem_activation_code`, `get_user_entitlement`, `admin_generate_codes`, `admin_revoke_code`.

لتطبيقها عبر Supabase SQL Editor:
- انسخ محتويات الملفات بالترتيب والصقها في واجهة SQL الخاصة بمشروعك في Supabase.

## ⚡ نشر وسيط الذكاء الاصطناعي (Cloudflare Worker)

يوجد كود الوسيط داخل مجلد `workers/ai-proxy/`:
```bash
cd workers/ai-proxy
npm install

# ضبط المتغيرات السرية في Cloudflare
npx wrangler secret put GEMINI_API_KEY
npx wrangler secret put SUPABASE_JWT_SECRET

# النشر
npm run deploy
```
